# 🦈 SharkNet — Free VLESS

> The worst free VPN you've ever used. But it works.

A personal subscription with free VLESS / Trojan / Shadowsocks servers. One profile — auto-selects the fastest server for you.

## 📥 Subscription

Add this link to your client as a Subscription URL:

https://raw.githubusercontent.com/harrys-png/V2raycfg/main/singbox.json

Use the raw link, not the GitHub page.

## ⚙️ How It Works

The subscription is a sing-box JSON config with:

- ⚡ SharkNet (urltest) — tests all servers every 5 minutes and connects to the fastest one
- Full server list — you can also pick any specific server manually

In Hiddify you'll see it as lowest or balance — that's Hiddify's own balancer, same logic as urltest.
